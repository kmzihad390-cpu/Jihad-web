TECH MASTER JIHAD WEBSITE
=========================

Files:
- index.html       Main website page
- style.css        Responsive design and styling
- script.js        Mobile menu, portfolio filters, image preview
- assets/          Logo, profile artwork, and portfolio screenshots

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.

FREE NETLIFY HOSTING
1. Visit https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag and drop the extracted folder (the folder containing index.html).
4. Netlify will publish the site and provide a free *.netlify.app address.

CUSTOM DOMAIN LATER
In Netlify, open Site configuration / Domain management and add your purchased domain.
Then follow the DNS instructions shown by Netlify and your domain registrar.

EDITING
- Change page text and links in index.html.
- Change colours, spacing, and fonts in style.css.
- Replace images in assets/ while keeping the same filenames, or update the paths in index.html.
